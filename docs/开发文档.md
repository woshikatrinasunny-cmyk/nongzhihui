# 农智汇开发文档

## 项目架构

### 技术栈
- **小程序端**: 微信小程序原生开发
- **后端**: Node.js + Express
- **数据库**: MongoDB
- **搜索引擎**: Elasticsearch（可选）

### 目录结构
```
├── miniprogram/          # 小程序前端
│   ├── pages/           # 页面
│   ├── utils/           # 工具函数
│   ├── images/          # 图片资源
│   ├── app.js           # 小程序入口
│   ├── app.json         # 小程序配置
│   └── app.wxss         # 全局样式
├── server/              # 后端服务
│   ├── models/          # 数据模型
│   ├── routes/          # 路由
│   ├── middleware/      # 中间件
│   └── app.js           # 服务入口
└── docs/                # 文档
```

## API 接口文档

### 基础响应格式
```json
{
  "code": 0,
  "message": "success",
  "data": {}
}
```

### 资源相关接口

#### 1. 获取热门资源
```
GET /api/resources/hot
```

响应：
```json
{
  "code": 0,
  "data": [
    {
      "id": "xxx",
      "title": "资源标题",
      "category": "law",
      "publishTime": "2024-01-01",
      "source": "来源"
    }
  ]
}
```

#### 2. 获取资源列表
```
GET /api/resources?category=law&page=1&pageSize=20
```

参数：
- category: 分类（law/policy/tech/culture）
- page: 页码
- pageSize: 每页数量

#### 3. 获取资源详情
```
GET /api/resources/:id
```

#### 4. 获取相关资源
```
GET /api/resources/:id/related
```

### 搜索相关接口

#### 1. 搜索资源
```
GET /api/search?keyword=关键词&page=1&pageSize=20
```

#### 2. 获取热门搜索
```
GET /api/search/hot
```

## 数据模型

### Resource（资源）
```javascript
{
  title: String,          // 标题
  summary: String,        // 摘要
  content: String,        // 正文
  category: String,       // 分类
  source: String,         // 来源
  sourceUrl: String,      // 原文链接
  tags: [String],         // 标签
  attachments: [{         // 附件
    name: String,
    url: String,
    size: String
  }],
  publishTime: Date,      // 发布时间
  viewCount: Number,      // 浏览量
  collectCount: Number,   // 收藏量
  status: String          // 状态
}
```

## 开发规范

### 代码规范
- 使用 ES6+ 语法
- 遵循 ESLint 规则
- 统一使用 2 空格缩进
- 变量命名使用驼峰命名法

### Git 提交规范
```
feat: 新功能
fix: 修复bug
docs: 文档更新
style: 代码格式调整
refactor: 重构
test: 测试相关
chore: 构建/工具相关
```

### 小程序开发注意事项
1. 图片资源尽量压缩，控制包大小
2. 合理使用缓存，减少请求
3. 注意用户体验，添加加载提示
4. 做好错误处理和异常提示
5. 遵循微信小程序开发规范

## 常见问题

### 1. 如何添加新的资源分类？
1. 修改 `server/models/Resource.js` 中的 enum
2. 更新小程序端的分类配置
3. 添加对应的图标资源

### 2. 如何优化搜索性能？
1. 使用 MongoDB 文本索引
2. 集成 Elasticsearch
3. 添加搜索结果缓存
4. 实现搜索建议功能

### 3. 如何实现数据爬取？
参考 `server/scripts/crawler.js` 示例代码，根据目标网站编写爬虫脚本。
