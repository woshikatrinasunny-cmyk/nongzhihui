# 农智汇网站修改指引

## 📋 项目架构说明

### 技术栈
- **前端框架**: Flask (Python) - 仅作为 Web 前端层
- **后端服务**: Node.js (Express) - 提供所有 API 和数据
- **模板引擎**: Jinja2
- **部署平台**: Render (Flask 应用)

## 🎯 核心原则

### ⚠️ 重要规则

1. **保持原有页面结构**
   - 不要修改 `base.html` 的整体布局
   - 不要删除或重命名现有的导航项
   - 添加新功能时，创建新的模板文件

2. **模板继承关系**
   ```
   base.html (基础模板)
   ├── index.html (首页)
   ├── search.html (搜索)
   ├── category.html (分类)
   ├── volunteer.html (志愿服务)
   └── ... (其他页面)
   ```

3. **样式规范**
   - 使用 `base.html` 中定义的 CSS 变量
   - 在各页面的 `{% block extra_style %}` 中添加页面特定样式
   - 保持与现有页面一致的设计风格

## 📝 修改指南

### 1. 添加新页面

#### 步骤 1: 创建模板文件
在 `html/templates/` 目录下创建新的 HTML 文件：

```html
{% extends "base.html" %}
{% set active_tab = 'your_page' %}
{% block title %}页面标题{% endblock %}

{% block extra_style %}
/* 页面特定样式 */
.your-page-class { ... }
{% endblock %}

{% block content %}
<div class="container">
  <!-- 页面内容 -->
</div>
{% endblock %}

{% block extra_script %}
<script>
// 页面特定 JavaScript
</script>
{% endblock %}
```

#### 步骤 2: 在 base.html 添加导航项
编辑 `html/templates/base.html`，在 `<nav class="side-nav">` 中添加：

```html
<a href="/your-page" class="nav-item {{ 'active' if active_tab=='your_page' }}">
  <span class="nav-emoji">🎯</span> 页面名称
</a>
```

#### 步骤 3: 在 app.py 添加路由
编辑 `html/app.py`，添加页面路由：

```python
@app.route('/your-page')
def your_page():
    # 如需从后端获取数据
    resp = api_get('/api/your-endpoint')
    data = extract_list(resp)
    
    return render_template('your_page.html', data=data)
```

#### 步骤 4: 添加 API 路由（如需要）
在 `html/app.py` 中添加 API 代理：

```python
@app.route('/api/your-endpoint')
def api_your_endpoint():
    resp = api_get('/api/your-endpoint')
    return jsonify(resp)
```

### 2. 修改现有页面

#### 修改页面内容
- 只修改对应模板文件的 `{% block content %}` 部分
- 不要修改 `{% extends "base.html" %}` 和基本结构

#### 修改页面样式
- 在 `{% block extra_style %}` 中添加或修改样式
- 使用现有的 CSS 变量（见下方列表）

#### 添加页面功能
- 在 `{% block extra_script %}` 中添加 JavaScript
- 通过 fetch API 调用后端接口

## 🔧 API 调用规范

### 前端调用 API

```javascript
// GET 请求
async function loadData() {
  try {
    const resp = await fetch('/api/your-endpoint');
    const result = await resp.json();
    
    if (result.success || result.code === 0) {
      // 处理数据
      console.log(result.data);
    } else {
      showToast(result.message || '加载失败');
    }
  } catch (e) {
    showToast('网络错误');
  }
}

// POST 请求
async function submitData(data) {
  try {
    const resp = await fetch('/api/your-endpoint', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify(data)
    });
    const result = await resp.json();
    
    if (result.success) {
      showToast('提交成功');
    }
  } catch (e) {
    showToast('提交失败');
  }
}
```

### Flask 代理 API

```python
# GET 请求代理
@app.route('/api/your-endpoint')
def api_your_endpoint():
    params = {
        'param1': request.args.get('param1', ''),
        'param2': request.args.get('param2', '')
    }
    resp = api_get('/api/your-endpoint', params)
    return jsonify(resp)

# POST 请求代理
@app.route('/api/your-endpoint', methods=['POST'])
def api_your_endpoint_post():
    data = request.get_json() or {}
    resp = api_post('/api/your-endpoint', data)
    return jsonify(resp)
```

## 🚀 部署流程

### 本地测试

1. 启动 Node.js 后端（可选，会自动使用 Render 后端）
   ```bash
   cd server
   node app.js
   ```

2. 启动 Flask 前端
   ```bash
   python html/app.py
   # 或
   cd html && python app.py
   ```

3. 访问 http://localhost:5000

### 部署到 Render

1. 提交代码到 Git
   ```bash
   git add .
   git commit -m "描述修改内容"
   git push
   ```

2. Render 会自动检测到更新并重新部署
   - 构建命令: `pip install -r requirements.txt`
   - 启动命令: `gunicorn app:app`

3. 查看部署日志
   - 访问 Render Dashboard
   - 查看 Logs 标签页

## ⚠️ 常见错误及避免方法

### 错误 1: 修改了 base.html 导致所有页面布局错乱
**避免方法**: 
- 不要修改 `base.html` 的 `<nav class="side-nav">` 结构
- 只在指定位置添加新的导航项
- 不要删除或重命名现有的 CSS 类

### 错误 2: 创建了新页面但没有添加路由
**避免方法**:
- 创建模板文件后，必须在 `app.py` 中添加对应路由
- 路由路径要与模板中的链接一致

### 错误 3: API 调用失败
**避免方法**:
- 确保 Flask 中有对应的 API 代理路由
- 检查 Node.js 后端是否有对应的 API 实现
- 查看浏览器控制台和 Flask 日志

### 错误 4: 样式不一致
**避免方法**:
- 使用 `base.html` 中定义的 CSS 变量
- 参考现有页面的样式写法
- 保持相同的间距、圆角、阴影等设计规范

## 🎨 设计规范

### 颜色使用
- 主色调: 绿色系（农业主题）
- 强调色: 使用 `var(--gd)` 或 `var(--g)`
- 背景色: 使用 `var(--bg)` 或 `var(--w)`
- 文本色: 使用 `var(--t)`, `var(--tl)`, `var(--tlr)`

### 间距规范
- 页面容器: `padding: 28px 32px`
- 卡片内边距: `padding: 20px-28px`
- 元素间距: `margin-bottom: 20px-30px`
- 小间距: `gap: 10px-16px`

### 圆角规范
- 卡片/按钮: `border-radius: var(--r)` (14px)
- 小元素: `border-radius: 8px-12px`
- 标签: `border-radius: 12px-20px`

### 阴影规范
- 默认: `box-shadow: var(--sh)`
- 悬停: `box-shadow: var(--shl)`

## 📞 问题排查

### 页面显示空白
1. 检查浏览器控制台是否有 JavaScript 错误
2. 检查 Flask 日志是否有模板渲染错误
3. 确认模板文件路径正确

### API 调用失败
1. 检查浏览器 Network 标签页
2. 查看 Flask 日志中的 API 调用记录
3. 确认 Node.js 后端是否正常运行

### 样式不生效
1. 清除浏览器缓存
2. 检查 CSS 选择器是否正确
3. 使用浏览器开发者工具检查元素样式
