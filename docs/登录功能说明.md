# 农智汇登录功能说明

## 功能概述

农智汇小程序实现了完整的微信登录功能，支持用户授权、信息更新、自动登录和退出登录。

## 登录流程

### 1. 首次登录

```
用户点击"点击登录" 
  ↓
调用 wx.login() 获取 code
  ↓
发送 code 到后端 /api/users/login
  ↓
后端调用微信接口获取 openid
  ↓
返回 token 和用户基本信息
  ↓
调用 wx.getUserProfile() 获取用户授权
  ↓
更新用户详细信息到后端
  ↓
保存 token 和 userInfo 到本地
  ↓
登录完成
```

### 2. 自动登录

小程序启动时，会自动检查本地是否有 token 和 userInfo：
- 如果有，直接使用，无需重新登录
- 如果没有，显示"点击登录"按钮

### 3. 退出登录

用户点击"退出"按钮：
- 清除全局变量中的用户信息
- 清除本地存储的 token 和 userInfo
- 返回未登录状态

## 前端实现

### app.js 全局方法

```javascript
// 微信登录
app.wxLogin()

// 获取用户信息（需要授权）
app.getUserProfile()

// 退出登录
app.logout()

// 自动登录
app.autoLogin()
```

### 使用示例

```javascript
// 在页面中使用
const app = getApp();

// 登录
app.wxLogin()
  .then(() => app.getUserProfile())
  .then((userInfo) => {
    console.log('登录成功', userInfo);
  })
  .catch((err) => {
    console.error('登录失败', err);
  });

// 检查登录状态
if (app.globalData.token && app.globalData.userInfo) {
  console.log('已登录');
} else {
  console.log('未登录');
}

// 退出登录
app.logout();
```

## 后端实现

### 数据模型 (User)

```javascript
{
  openid: String,        // 微信 openid（唯一标识）
  nickName: String,      // 昵称
  avatarUrl: String,     // 头像
  gender: Number,        // 性别：0未知 1男 2女
  country: String,       // 国家
  province: String,      // 省份
  city: String,          // 城市
  language: String,      // 语言
  lastLoginTime: Date,   // 最后登录时间
  status: String         // 状态：active/banned
}
```

### API 接口

#### 1. 登录接口

**POST /api/users/login**

请求：
```json
{
  "code": "微信登录code"
}
```

响应：
```json
{
  "code": 0,
  "message": "登录成功",
  "data": {
    "token": "JWT Token",
    "userInfo": {
      "openid": "用户openid",
      "nickName": "昵称",
      "avatarUrl": "头像URL"
    }
  }
}
```

#### 2. 更新用户信息

**POST /api/users/update**

请求：
```json
{
  "openid": "用户openid",
  "nickName": "昵称",
  "avatarUrl": "头像URL",
  "gender": 1,
  "country": "中国",
  "province": "广东",
  "city": "深圳"
}
```

响应：
```json
{
  "code": 0,
  "message": "更新成功",
  "data": {
    // 完整用户信息
  }
}
```

#### 3. 获取用户信息

**GET /api/users/info?openid=xxx**

响应：
```json
{
  "code": 0,
  "data": {
    "openid": "用户openid",
    "nickName": "昵称",
    "avatarUrl": "头像URL",
    // 其他信息...
  }
}
```

## 开发环境配置

### 1. 后端配置

编辑 `server/.env` 文件：

```env
# 开发环境
NODE_ENV=development

# 微信小程序配置（生产环境需要）
WECHAT_APPID=your-appid
WECHAT_SECRET=your-secret

# JWT配置
JWT_SECRET=your-secret-key
JWT_EXPIRES_IN=7d
```

### 2. 开发模式

在开发环境下（NODE_ENV=development），后端会自动使用测试用户，无需配置微信 AppID 和 Secret。

测试用户信息：
```javascript
{
  openid: 'test_user_' + timestamp,
  nickName: '测试用户',
  avatarUrl: 'https://via.placeholder.com/100'
}
```

### 3. 生产模式

生产环境需要：
1. 在微信公众平台注册小程序
2. 获取 AppID 和 AppSecret
3. 配置到 `.env` 文件
4. 设置 `NODE_ENV=production`

## 权限控制

某些页面需要登录后才能访问：

```javascript
// 在 my.js 中
const needLoginPages = [
  '/pages/collect/collect',
  '/pages/history/history'
];

if (needLoginPages.includes(url) && !this.data.hasLogin) {
  wx.showModal({
    title: '提示',
    content: '该功能需要登录后使用',
    confirmText: '去登录',
    success: (res) => {
      if (res.confirm) {
        this.getUserProfile();
      }
    }
  });
  return;
}
```

## 数据存储

### 本地存储

```javascript
// 存储
wx.setStorageSync('token', token);
wx.setStorageSync('userInfo', userInfo);

// 读取
const token = wx.getStorageSync('token');
const userInfo = wx.getStorageSync('userInfo');

// 清除
wx.removeStorageSync('token');
wx.removeStorageSync('userInfo');
```

### 全局变量

```javascript
// app.js
globalData: {
  token: null,
  userInfo: null,
  openid: null
}

// 使用
const app = getApp();
console.log(app.globalData.userInfo);
```

## 安全建议

1. **Token 管理**
   - Token 存储在本地，有效期7天
   - 过期后需要重新登录
   - 敏感操作需要验证 Token

2. **用户信息保护**
   - 不要在前端存储敏感信息
   - 使用 HTTPS 传输数据
   - 后端验证所有请求

3. **防止重放攻击**
   - Token 一次性使用
   - 添加时间戳验证
   - 限制请求频率

## 常见问题

### 1. 登录失败

**问题**：点击登录没有反应

**解决**：
- 检查后端服务是否启动
- 查看控制台错误信息
- 确认网络请求是否成功

### 2. 用户信息不显示

**问题**：登录成功但用户信息不显示

**解决**：
- 检查 globalData 是否正确设置
- 确认页面 onShow 时重新获取数据
- 查看 setData 是否执行

### 3. 自动登录失败

**问题**：重新打开小程序需要重新登录

**解决**：
- 检查本地存储是否被清除
- 确认 Token 是否过期
- 查看 app.js 的 autoLogin 方法

### 4. 生产环境登录失败

**问题**：开发环境正常，生产环境登录失败

**解决**：
- 确认已配置 WECHAT_APPID 和 WECHAT_SECRET
- 检查小程序后台配置
- 确认服务器域名已备案
