## 组件列表

### 1. filter-panel（筛选面板）

高级搜索筛选组件，支持分类、排序、日期范围筛选。

#### 使用方法

```json
// 在页面的 json 文件中引入
{
  "usingComponents": {
    "filter-panel": "/components/filter-panel/filter-panel"
  }
}
```

```xml
<!-- 在 wxml 中使用 -->
<filter-panel 
  show="{{showFilter}}"
  filters="{{filters}}"
  bind:confirm="onFilterConfirm"
  bind:close="onFilterClose">
</filter-panel>
```

```javascript
// 在 js 中处理
Page({
  data: {
    showFilter: false,
    filters: {
      category: '',
      sortBy: 'relevance',
      startDate: '',
      endDate: ''
    }
  },

  toggleFilter() {
    this.setData({ showFilter: !this.data.showFilter });
  },

  onFilterConfirm(e) {
    this.setData({
      filters: e.detail,
      showFilter: false
    });
    // 执行搜索
    this.performSearch();
  },

  onFilterClose() {
    this.setData({ showFilter: false });
  }
})
```

#### 属性

| 属性 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| show | Boolean | false | 是否显示面板 |
| filters | Object | {} | 筛选条件对象 |

#### 事件

| 事件名 | 说明 | 返回值 |
|--------|------|--------|
| confirm | 确认筛选 | filters 对象 |
| close | 关闭面板 | 无 |

#### filters 对象结构

```javascript
{
  category: '',        // 分类：law/policy/tech/culture
  sortBy: 'relevance', // 排序：relevance/time/views/collects
  startDate: '',       // 开始日期：YYYY-MM-DD
  endDate: ''          // 结束日期：YYYY-MM-DD
}
```

## 工具函数

### request.js

封装的网络请求工具。

```javascript
const { get, post, put, delete: del } = require('../../utils/request.js');

// GET 请求
get('/resources/hot').then(res => {
  console.log(res.data);
});

// POST 请求
post('/collect/toggle', {
  userId: 'test_user',
  resourceId: '1'
}).then(res => {
  console.log(res.message);
});
```

### util.js

通用工具函数。

```javascript
const { formatTime, formatDate, formatRelativeTime, debounce, throttle } = require('../../utils/util.js');

// 格式化时间
formatTime(new Date()); // "2024-02-06 10:30:00"

// 格式化日期
formatDate(new Date()); // "2024-02-06"

// 相对时间
formatRelativeTime(Date.now() - 3600000); // "1小时前"

// 防抖
const debouncedSearch = debounce(search, 500);

// 节流
const throttledScroll = throttle(onScroll, 200);
```

## 最佳实践

1. **数据请求**: 统一使用 `request.js` 封装的方法
2. **错误处理**: 所有请求都应有 catch 处理
3. **加载状态**: 长时间操作显示 loading
4. **空状态**: 列表为空时显示友好提示
5. **用户反馈**: 操作成功/失败都要有 toast 提示
6. **性能优化**: 使用防抖节流优化频繁操作
7. **代码复用**: 相同逻辑抽取为组件或工具函数

## 调试技巧

1. 使用 `console.log` 打印关键数据
2. 在开发者工具中查看 Network 请求
3. 使用 Storage 面板查看本地存储
4. 利用 AppData 面板查看页面数据
5. 使用 Wxml 面板检查页面结构
