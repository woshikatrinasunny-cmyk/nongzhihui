# 农智汇快速启动指南

## 第一步：安装MongoDB到D盘

### 1. 关闭当前安装程序
- 点击"OK"关闭错误提示
- 关闭MongoDB安装程序

### 2. 清理C盘空间（临时方案）
如果必须安装到C盘，先清理空间：
```cmd
# 清理临时文件
cleanmgr

# 或者删除一些不需要的文件，释放至少4GB空间
```

### 3. 重新安装到D盘（推荐）

**方法一：使用自定义安装**
1. 重新运行MongoDB安装程序
2. 选择"Custom"（自定义）
3. 点击"Browse"按钮
4. 选择D盘路径：`D:\MongoDB\Server\8.2\`
5. 继续安装

**方法二：使用命令行安装**
```cmd
# 以管理员身份运行CMD
# 进入安装包所在目录，然后执行：
msiexec /i mongodb-windows-x86_64-8.2.4-signed.msi ^
  INSTALLLOCATION="D:\MongoDB\Server\8.2\" ^
  ADDLOCAL="ServerService,Client" ^
  /qb

# 等待安装完成
```

### 4. 配置MongoDB数据目录

安装完成后，创建数据和日志目录：

```cmd
# 创建目录
mkdir D:\MongoDB\data
mkdir D:\MongoDB\log

# 创建配置文件
notepad D:\MongoDB\mongod.cfg
```

在配置文件中输入：
```yaml
systemLog:
  destination: file
  path: D:\MongoDB\log\mongod.log
storage:
  dbPath: D:\MongoDB\data
net:
  port: 27017
  bindIp: 127.0.0.1
```

### 5. 启动MongoDB服务

```cmd
# 方法一：使用Windows服务（推荐）
net start MongoDB

# 方法二：手动启动
"D:\MongoDB\Server\8.2\bin\mongod.exe" --config "D:\MongoDB\mongod.cfg"
```

### 6. 验证MongoDB是否运行

```cmd
# 打开新的CMD窗口
"D:\MongoDB\Server\8.2\bin\mongosh.exe"

# 如果成功连接，会看到MongoDB shell提示符
# 输入以下命令测试：
show dbs
exit
```

## 第二步：启动后端服务

### 1. 进入后端目录

```cmd
# 切换到项目目录
cd /d D:\your-project-path\server

# 如果项目在其他位置，替换为实际路径
```

### 2. 安装依赖（首次运行）

```cmd
npm install
```

如果安装慢，可以使用国内镜像：
```cmd
npm config set registry https://registry.npmmirror.com
npm install
```

### 3. 初始化数据库

```cmd
npm run init-data
```

你应该看到类似输出：
```
MongoDB 连接成功
已清空现有数据
成功插入 10 条测试数据
数据初始化完成
```

### 4. 启动后端服务

```cmd
# 开发模式（自动重启）
npm run dev

# 或者生产模式
npm start
```

看到以下输出表示成功：
```
MongoDB 连接成功
服务器运行在端口 3000
```

### 5. 测试后端接口

打开浏览器访问：
```
http://localhost:3000/health
```

应该看到：
```json
{
  "status": "ok",
  "message": "服务运行正常"
}
```

## 第三步：启动小程序

### 1. 打开微信开发者工具

### 2. 导入项目
- 点击"导入项目"
- 选择项目目录：`miniprogram`文件夹
- AppID：选择"测试号"或输入你的AppID

### 3. 构建npm（首次运行）

如果还没有构建npm：
1. 点击菜单：工具 -> 构建 npm
2. 等待构建完成

### 4. 配置不校验域名

开发阶段需要关闭域名校验：
1. 点击右上角"详情"
2. 勾选"不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书"

### 5. 编译运行

点击"编译"按钮，小程序应该正常显示。

## 常见问题解决

### 问题1：MongoDB连接失败

**错误信息**：`MongoNetworkError: connect ECONNREFUSED`

**解决方法**：
```cmd
# 检查MongoDB服务是否运行
net start MongoDB

# 或者手动启动
"D:\MongoDB\Server\8.2\bin\mongod.exe" --config "D:\MongoDB\mongod.cfg"
```

### 问题2：小程序显示"暂无资源"

**原因**：后端服务未启动或数据库没有数据

**解决方法**：
```cmd
# 1. 确保后端服务运行
cd server
npm run dev

# 2. 初始化数据
npm run init-data

# 3. 测试接口
curl http://localhost:3000/api/resources/hot
```

### 问题3：小程序请求失败

**错误信息**：`request:fail`

**解决方法**：
1. 检查后端服务是否运行（访问 http://localhost:3000/health）
2. 检查小程序是否勾选"不校验合法域名"
3. 检查 `miniprogram/app.js` 中的 `apiUrl` 配置

### 问题4：npm install 失败

**解决方法**：
```cmd
# 清理缓存
npm cache clean --force

# 使用国内镜像
npm config set registry https://registry.npmmirror.com

# 重新安装
npm install
```

### 问题5：端口被占用

**错误信息**：`Error: listen EADDRINUSE: address already in use :::3000`

**解决方法**：
```cmd
# 查找占用端口的进程
netstat -ano | findstr :3000

# 结束进程（替换PID为实际进程ID）
taskkill /PID <PID> /F

# 或者修改端口
# 编辑 server/.env 文件，改为其他端口如 3001
```

## 完整启动脚本

创建一个批处理文件 `start-all.bat`：

```batch
@echo off
echo ========================================
echo 农智汇项目启动脚本
echo ========================================

echo.
echo [1/3] 启动MongoDB服务...
net start MongoDB
if errorlevel 1 (
    echo MongoDB启动失败，请检查服务是否已安装
    pause
    exit
)

echo.
echo [2/3] 启动后端服务...
cd /d %~dp0server
start "农智汇后端" cmd /k "npm run dev"

echo.
echo [3/3] 等待5秒后打开微信开发者工具...
timeout /t 5

echo.
echo ========================================
echo 启动完成！
echo 后端地址: http://localhost:3000
echo 请在微信开发者工具中打开小程序项目
echo ========================================
pause
```

保存后双击运行即可一键启动所有服务。
