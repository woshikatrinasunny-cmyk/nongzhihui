# 农智汇完整部署指南

## 一、环境准备

### 1.1 系统要求

- **操作系统**：Windows 10/11、macOS 10.15+、Linux
- **Node.js**：>= 14.0.0（推荐 16.x 或 18.x）
- **MongoDB**：>= 4.4
- **微信开发者工具**：最新版本

### 1.2 安装 Node.js

访问 [Node.js 官网](https://nodejs.org/) 下载并安装。

验证安装：
```bash
node -v
npm -v
```

### 1.3 安装 MongoDB

#### Windows
1. 访问 [MongoDB 官网](https://www.mongodb.com/try/download/community) 下载安装包
2. 运行安装程序，选择"Complete"安装
3. 配置为 Windows 服务，自动启动

#### macOS
```bash
brew tap mongodb/brew
brew install mongodb-community
brew services start mongodb-community
```

#### Linux (Ubuntu)
```bash
wget -qO - https://www.mongodb.org/static/pgp/server-4.4.asc | sudo apt-key add -
echo "deb [ arch=amd64,arm64 ] https://repo.mongodb.org/apt/ubuntu focal/mongodb-org/4.4 multiverse" | sudo tee /etc/apt/sources.list.d/mongodb-org-4.4.list
sudo apt-get update
sudo apt-get install -y mongodb-org
sudo systemctl start mongod
```

验证安装：
```bash
mongosh
```

### 1.4 安装微信开发者工具

1. 访问 [微信开放平台](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 下载对应系统的开发者工具
3. 安装并登录

## 二、后端部署

### 2.1 克隆项目

```bash
git clone <项目地址>
cd nongzhihui
```

### 2.2 安装后端依赖

```bash
cd server
npm install
```

### 2.3 配置环境变量

复制 `.env.example` 为 `.env`：

```bash
cp .env.example .env
```

编辑 `.env` 文件：

```env
# 服务器配置
PORT=3000
NODE_ENV=development

# 数据库配置
MONGODB_URI=mongodb://localhost:27017/nongzhihui

# JWT配置
JWT_SECRET=your-secret-key-change-in-production
JWT_EXPIRES_IN=7d

# 微信小程序配置（可选，用于正式登录）
WECHAT_APPID=your-wechat-appid
WECHAT_SECRET=your-wechat-secret
```

### 2.4 初始化数据库

```bash
npm run init-data
```

这将创建测试数据，包括：
- 10条涉农资源（法律法规、政策文件、农技手册、乡土文献）
- 各类分类和标签

### 2.5 启动后端服务

开发模式（自动重启）：
```bash
npm run dev
```

生产模式：
```bash
npm start
```

服务启动后，访问 `http://localhost:3000/health` 检查服务状态。

## 三、小程序部署

### 3.1 安装小程序依赖

```bash
cd miniprogram
npm install
```

### 3.2 构建 npm

1. 打开微信开发者工具
2. 导入项目，选择 `miniprogram` 目录
3. 点击菜单：工具 -> 构建 npm
4. 等待构建完成

### 3.3 配置 API 地址

编辑 `miniprogram/app.js`，修改 API 地址：

```javascript
App({
  globalData: {
    apiUrl: 'http://127.0.0.1:3000',  // 开发环境
    // apiUrl: 'https://your-domain.com',  // 生产环境
    userInfo: null
  },
  // ...
})
```

### 3.4 配置小程序信息

编辑 `miniprogram/project.config.json`，修改 `appid`：

```json
{
  "appid": "your-appid",  // 替换为你的小程序 AppID
  // ...
}
```

### 3.5 启动小程序

1. 在微信开发者工具中打开项目
2. 点击"编译"按钮
3. 在模拟器中预览效果

## 五、生产环境部署

### 5.1 后端部署

#### 使用 PM2 部署

1. 安装 PM2：
```bash
npm install -g pm2
```

2. 启动服务：
```bash
cd server
pm2 start app.js --name nongzhihui-server
```

3. 设置开机自启：
```bash
pm2 startup
pm2 save
```

4. 查看日志：
```bash
pm2 logs nongzhihui-server
```

#### 使用 Docker 部署

1. 创建 `Dockerfile`：
```dockerfile
FROM node:16-alpine
WORKDIR /app
COPY package*.json ./
RUN npm install --production
COPY . .
EXPOSE 3000
CMD ["node", "app.js"]
```

2. 构建镜像：
```bash
docker build -t nongzhihui-server .
```

3. 运行容器：
```bash
docker run -d -p 3000:3000 --name nongzhihui nongzhihui-server
```

### 5.2 配置 Nginx 反向代理

创建 Nginx 配置文件：

```nginx
server {
    listen 80;
    server_name your-domain.com;

    location /api {
        proxy_pass http://localhost:3000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }
}
```

### 5.3 配置 HTTPS

使用 Let's Encrypt 免费证书：

```bash
sudo apt-get install certbot python3-certbot-nginx
sudo certbot --nginx -d your-domain.com
```

## 六、常见问题

### 6.1 MongoDB 连接失败

**问题**：`MongoNetworkError: connect ECONNREFUSED`

**解决**：
1. 检查 MongoDB 服务是否启动
2. 检查 `.env` 中的连接字符串是否正确
3. 检查防火墙设置

### 6.2 小程序请求失败

**问题**：`request:fail`

**解决**：
1. 检查后端服务是否启动
2. 在微信开发者工具中，勾选"不校验合法域名"
3. 生产环境需在小程序后台配置服务器域名

### 6.3 npm 构建失败

**问题**：构建 npm 时报错

**解决**：
1. 删除 `miniprogram/node_modules` 和 `miniprogram/miniprogram_npm`
2. 重新执行 `npm install`
3. 在开发者工具中重新构建 npm

### 6.4 收藏功能不生效

**问题**：点击收藏没有反应

**解决**：
1. 检查后端 `/api/collect/toggle` 接口是否正常
2. 查看控制台错误信息
3. 确认 `fixedUserId` 已正确设置

## 九、安全建议

1. **环境变量**：不要将 `.env` 文件提交到版本控制
2. **JWT 密钥**：使用强随机密钥
3. **HTTPS**：生产环境必须使用 HTTPS
4. **输入验证**：对所有用户输入进行验证和过滤
5. **访问控制**：实现用户权限管理
6. **定期更新**：及时更新依赖包，修复安全漏洞
