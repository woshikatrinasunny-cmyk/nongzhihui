## 功能特点

### 1. 多平台聚合

一次搜索，同时查询：
- ✅ 中国政府网
- ✅ 全国人大网
- ✅ 农业农村部
- ✅ 国家政务服务平台

### 2. 权威等级标识

每条结果都标注权威等级：
- 🔴 **官方** - 政府机构发布
- 🔵 **专业** - 科研机构、高校
- ⚪ **一般** - 其他来源

### 3. 平台筛选

可以按平台筛选结果：
```
[全部平台 ▼]
  ├─ 全部平台 (25)
  ├─ 全国人大网 (8)
  ├─ 中国政府网 (12)
  └─ 农业农村部 (5)
```

### 4. 分类标签

资源自动分类：
- 📕 法律 - 法律法规、司法解释
- 📗 政策 - 政策文件、通知意见
- 📘 技术 - 技术指南、操作手册
- 📙 文化 - 乡土文献、民俗文化

### 5. 外部资源处理

点击外部资源时：
```
┌─────────────────────────┐
│      外部资源提示        │
├─────────────────────────┤
│ 该资源来自外部平台，     │
│ 是否在浏览器中打开？     │
│                         │
│   [取消]      [打开]    │
└─────────────────────────┘
```

## 用户体验

### 搜索流程

```
1. 用户输入关键词
   ↓
2. 显示"搜索中..."
   ↓
3. 并发查询多个平台（1-2秒）
   ↓
4. 显示聚合结果
   ↓
5. 用户可以：
   - 查看详情
   - 按平台筛选
   - 跳转到原平台
```

### 性能表现

- ⚡ 搜索响应：1-2秒
- 💾 缓存命中：< 100ms
- 🔄 并发查询：同时查询4-6个平台
- 📊 结果合并：自动去重和排序

## 技术实现

### 后端API

```javascript
// 搜索接口
GET /api/search?keyword=农村土地承包法&includeExternal=true

// 响应格式
{
  "code": 0,
  "data": {
    "list": [...],        // 搜索结果列表
    "total": 25,          // 总数
    "hasMore": true,      // 是否有更多
    "platforms": [...],   // 平台统计
    "sources": {
      "local": 0,         // 本地结果数
      "external": 25      // 外部结果数
    }
  }
}
```

### 前端展示

```javascript
// 搜索请求
wx.request({
  url: `${apiUrl}/api/search`,
  data: {
    keyword: '农村土地承包法',
    includeExternal: true,  // 开启全网搜索
    sortBy: 'relevance',    // 排序方式
    page: 1,
    pageSize: 20
  }
});
```

