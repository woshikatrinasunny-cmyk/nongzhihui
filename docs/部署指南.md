# 农智汇小程序部署指南

## 一、前置准备

### 1. 微信小程序账号
- 注册微信小程序账号（https://mp.weixin.qq.com）
- 获取 AppID 和 AppSecret
- 配置服务器域名（需要备案的 HTTPS 域名）

### 2. 服务器环境
- Node.js 14+ 
- MongoDB 4.4+
- Elasticsearch 7.x（可选，用于高级搜索）
- Nginx（用于反向代理）

## 二、小程序端部署

### 1. 配置 AppID
修改 `miniprogram/project.config.json`：
```json
{
  "appid": "你的小程序AppID"
}
```

### 2. 配置 API 地址
修改 `miniprogram/app.js`：
```javascript
globalData: {
  apiUrl: 'https://your-domain.com/api'
}
```

### 3. 上传代码
1. 使用微信开发者工具打开项目
2. 点击"上传"按钮
3. 填写版本号和项目备注
4. 提交审核

## 三、后端服务部署

### 1. 安装依赖
```bash
cd server
npm install
```

### 2. 配置环境变量
复制 `.env.example` 为 `.env`，修改配置：
```
PORT=3000
MONGODB_URI=mongodb://localhost:27017/nongzhihui
JWT_SECRET=your-secret-key
ELASTICSEARCH_HOST=http://localhost:9200
NODE_ENV=production
```

### 3. 启动服务
```bash
# 开发环境
npm run dev

# 生产环境
npm start
```

### 4. 使用 PM2 管理进程（推荐）
```bash
npm install -g pm2
pm2 start app.js --name nongzhihui
pm2 save
pm2 startup
```

## 四、Nginx 配置

```nginx
server {
    listen 80;
    server_name your-domain.com;
    return 301 https://$server_name$request_uri;
}

server {
    listen 443 ssl;
    server_name your-domain.com;
    
    ssl_certificate /path/to/cert.pem;
    ssl_certificate_key /path/to/key.pem;
    
    location /api {
        proxy_pass http://localhost:3000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }
}
```

## 五、数据库初始化

### 1. 创建数据库
```bash
mongo
use nongzhihui
```

### 2. 导入初始数据
```bash
mongoimport --db nongzhihui --collection resources --file data/resources.json
```
