# 农智汇测试指南

## 一、测试环境准备

### 1.1 启动后端服务

```bash
cd server
npm run dev
```

确保服务在 `http://localhost:3000` 运行。

### 1.2 初始化测试数据

```bash
cd server
npm run init-data
```

这将创建 10 条测试资源数据。

### 1.3 启动小程序

1. 打开微信开发者工具
2. 导入 `miniprogram` 目录
3. 点击"编译"

## 三、接口测试

### 3.1 使用 Postman 测试

#### 资源接口

```
GET http://localhost:3000/api/resources/hot
GET http://localhost:3000/api/resources/latest
GET http://localhost:3000/api/resources?category=law&page=1&pageSize=20
GET http://localhost:3000/api/resources/1
GET http://localhost:3000/api/resources/1/related
```

#### 搜索接口

```
GET http://localhost:3000/api/search?keyword=土地
GET http://localhost:3000/api/search/hot
```

#### 收藏接口

```
POST http://localhost:3000/api/collect/toggle
Body: {
  "userId": "test_user",
  "resourceId": "1"
}

GET http://localhost:3000/api/collect/list?userId=test_user
```

#### 历史接口

```
POST http://localhost:3000/api/history/add
Body: {
  "userId": "test_user",
  "resourceId": "1"
}

GET http://localhost:3000/api/history/list?userId=test_user
DELETE http://localhost:3000/api/history/clear
Body: {
  "userId": "test_user"
}
```

#### 反馈接口

```
POST http://localhost:3000/api/feedback/add
Body: {
  "userId": "test_user",
  "content": "测试反馈",
  "contact": "13800138000"
}

GET http://localhost:3000/api/feedback/list?userId=test_user
```

### 3.2 预期响应格式

成功响应：
```json
{
  "code": 0,
  "message": "成功",
  "data": {}
}
```

失败响应：
```json
{
  "code": -1,
  "message": "错误信息",
  "error": "详细错误"
}
```
