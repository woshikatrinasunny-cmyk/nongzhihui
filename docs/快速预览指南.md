# 快速预览指南

## 方法一：使用微信开发者工具（推荐）

### 步骤
1. **下载工具**：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html
2. **打开工具**，选择"导入项目"
3. **选择目录**：选择项目中的 `miniprogram` 文件夹
4. **AppID**：选择"测试号"（无需注册）
5. **点击导入**，即可在模拟器中预览

### 真机预览
- 点击工具栏"预览"按钮
- 用微信扫描生成的二维码
- 在手机上查看真实效果

## 方法二：临时解决图片问题

如果提示图片加载失败，可以：

### 方案 1：创建占位图片
在 `miniprogram/images/` 目录创建空白图片文件（任意图片改名即可）

### 方案 2：修改为文字显示
暂时注释掉图片标签，使用文字代替：

```xml
<!-- 原代码 -->
<image src="/images/search.png"></image>

<!-- 改为 -->
<!-- <image src="/images/search.png"></image> -->
<text>🔍</text>
```

### 方案 3：使用 emoji 图标
直接在代码中使用 emoji：
- 🏠 首页
- 📚 分类  
- 👤 我的
- 🔍 搜索
- ⚖️ 法律
- 📋 政策
- 🌾 农技
- 📖 文献

## 方法三：在线预览（需要部署）

1. 部署后端服务到服务器
2. 配置小程序服务器域名
3. 上传代码到微信后台
4. 提交审核后发布

## 注意事项

1. **首次使用**建议选择"测试号"，无需注册
2. **网络请求**在开发工具中需要关闭"不校验合法域名"
3. **真机预览**需要配置合法的 HTTPS 域名
4. **图片资源**可以先用占位图，后续再替换

## 常见问题

### Q: 提示"未找到入口文件"
A: 确保选择的是 `miniprogram` 文件夹，不是项目根目录

### Q: 页面显示空白
A: 检查 app.json 中的 pages 配置是否正确

### Q: 图片不显示
A: 暂时注释掉图片标签，或使用文字/emoji 代替

### Q: 网络请求失败
A: 开发工具中勾选"不校验合法域名、web-view、TLS版本"
