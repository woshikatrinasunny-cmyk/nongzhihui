# 全网聚合搜索功能说明

## 核心特性

### 🌐 纯API聚合模式

本项目采用**纯实时API聚合**架构，无需维护本地数据库和爬虫系统。

#### 优势

1. **零维护成本**
   - 不需要运行爬虫
   - 不需要定时更新数据
   - 不需要清理过期内容
   - 不需要监控数据质量

2. **数据永远最新**
   - 每次搜索都是实时查询
   - 直接从官方平台获取最新数据
   - 无数据延迟问题

3. **资源量巨大**
   - 可搜索全网所有公开资源
   - 不受本地存储限制
   - 覆盖多个权威平台

4. **部署简单**
   - 只需启动后端服务
   - 无需配置爬虫
   - 无需大容量数据库

## 工作原理

### 搜索流程

```
用户输入关键词
    ↓
并发查询多个平台API
    ├─ 中国政府网
    ├─ 农业农村部
    ├─ 全国人大网
    ├─ 国家政务服务平台
    └─ 其他平台...
    ↓
结果合并、去重、排序
    ↓
返回给用户
```

### 缓存机制

为了提升性能和减少API调用：
- 搜索结果缓存1小时
- 热门关键词优先缓存
- 自动清理过期缓存

## API对接指南

### 示例：对接中国政府网搜索API

```javascript
async searchGovCn(keyword, options) {
  try {
    // 实际API调用
    const response = await axios.get('http://sousuo.gov.cn/s.htm', {
      params: {
        q: keyword,
        n: 10,
        t: 'zhengce',
        timetype: 'timeqb',
        mintime: '',
        maxtime: '',
        sort: 'relevance'
      },
      headers: {
        'User-Agent': 'Mozilla/5.0...'
      },
      timeout: 5000
    });

    // 解析响应
    const results = this.parseGovCnResponse(response.data);
    return this.normalizeResults(results, 'govCn');
  } catch (error) {
    console.error('中国政府网API调用失败:', error);
    // 降级到模拟数据
    return this.getMockData('govCn', keyword);
  }
}
```

## 性能优化

### 1. 并发查询

所有平台API并发调用，不会相互阻塞：

```javascript
const promises = [
  this.searchGovCn(keyword),
  this.searchMOA(keyword),
  this.searchNPC(keyword)
];

const results = await Promise.allSettled(promises);
```

### 2. 超时控制

每个API调用设置5秒超时，避免长时间等待：

```javascript
axios.get(url, { timeout: 5000 })
```

### 3. 缓存策略

- 热门关键词缓存1小时
- 冷门关键词缓存30分钟
- 自动清理过期缓存

### 4. 降级处理

API失败时自动降级到模拟数据，确保用户体验。

```javascript
// 2. 实现搜索方法
async searchNewPlatform(keyword, options) {
  // 实现API调用逻辑

// 3. 在 searchExternal 中添加分支
case 'newPlatform':
  results = await this.searchNewPlatform(keyword, options);
  break;
```

## 注意事项

1. **API调用频率**
   - 遵守各平台的API调用限制
   - 使用缓存减少重复请求
   - 避免短时间内大量请求

2. **数据版权**
   - 标注资源来源
   - 提供原文链接
   - 不存储完整内容

3. **用户体验**
   - 显示加载状态
   - 提供平台筛选
   - 标注资源权威性

4. **错误处理**
   - API失败时优雅降级
   - 显示友好的错误提示
   - 记录错误日志

## 常见问题

### Q: 为什么不使用爬虫？

A: 爬虫需要持续维护，容易被反爬，数据更新不及时。纯API模式更稳定、更高效。

### Q: 如果API不可用怎么办？

A: 系统会自动降级到模拟数据，确保基本功能可用。同时会记录错误日志，方便排查。

### Q: 搜索速度会很慢吗？

A: 不会。我们使用并发查询和缓存机制，通常1-2秒内返回结果。

### Q: 可以添加更多平台吗？

A: 可以！系统设计支持灵活扩展，添加新平台非常简单。
