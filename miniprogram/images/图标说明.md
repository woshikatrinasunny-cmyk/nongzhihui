# 底部导航栏图标说明

## 需要的图标文件

请在 `miniprogram/images/` 文件夹中添加以下6个图标文件：

### 1. 首页图标
- **tab-home.png** (未选中状态) - 建议使用 🏠 房子图标，灰色
- **tab-home-active.png** (选中状态) - 建议使用 🏠 房子图标，绿色 #2E7D32

### 2. 分类图标
- **tab-category.png** (未选中状态) - 建议使用 📋 列表图标，灰色
- **tab-category-active.png** (选中状态) - 建议使用 📋 列表图标，绿色 #2E7D32

### 3. 我的图标
- **tab-my.png** (未选中状态) - 建议使用 👤 用户图标，灰色
- **tab-my-active.png** (选中状态) - 建议使用 👤 用户图标，绿色 #2E7D32

## 图标规格

- **尺寸**: 81px × 81px (推荐)
- **格式**: PNG（支持透明背景）
- **颜色**: 
  - 未选中: #81C784 (浅绿)
  - 选中: #2E7D32 (深绿)

## 快速获取图标的方法

### 方法1：使用 iconfont（推荐）
1. 访问 https://www.iconfont.cn/
2. 搜索 "home"、"category"、"user"
3. 下载PNG格式，尺寸选择 81px
4. 使用图片编辑工具改变颜色

### 方法2：使用 Emoji 转图片
1. 使用在线工具将 Emoji 转为图片
2. 🏠 (首页)、📋 (分类)、👤 (我的)
3. 调整颜色和大小

### 方法3：临时使用纯色方块（测试用）
如果暂时没有图标，可以先创建纯色方块图片：
- 创建 81×81 的纯色PNG
- 未选中用浅色，选中用深色

## 放置位置

将所有6个图标文件放在：
```
miniprogram/images/
├── tab-home.png
├── tab-home-active.png
├── tab-category.png
├── tab-category-active.png
├── tab-my.png
└── tab-my-active.png
```

## 注意事项

1. 文件名必须完全一致（包括大小写）
2. 图标背景必须透明
3. 图标线条要清晰，不要太细
4. 建议使用简洁的线性图标风格
