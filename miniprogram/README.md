# 农智汇小程序

## 项目说明

农智汇是一款专注于涉农知识聚合的智能检索小程序，为农民提供便捷的法律、政策、技术资源查询服务。

## 功能模块

### 首页
- 搜索框
- 轮播图
- 快捷入口（法律法规、政策文件、农技手册、乡土文献）
- 热门资源
- 最新政策

### 搜索
- 关键词搜索
- 搜索历史
- 热门搜索
- 搜索结果展示

### 资源详情
- 标题和元信息
- 摘要和正文
- 附件下载
- 收藏和分享
- 相关推荐

### 分类浏览
- 分类导航
- 资源列表
- 分页加载

### 个人中心
- 用户信息
- 我的收藏
- 浏览历史
- 意见反馈
- 关于我们

## 开发指南

### 1. 配置 AppID
修改 `project.config.json` 中的 `appid` 字段

### 2. 配置 API 地址
修改 `app.js` 中的 `apiUrl` 字段

### 3. 准备图片资源
将所需图标放入 `images` 目录：
- home.png / home-active.png
- category.png / category-active.png
- my.png / my-active.png
- search.png
- law.png
- policy.png
- tech.png
- culture.png
- 等等

### 4. 使用微信开发者工具
1. 打开微信开发者工具
2. 导入项目
3. 选择 `miniprogram` 目录
4. 开始开发

## 注意事项

1. 确保后端服务已启动
2. 配置合法的服务器域名
3. 图片资源需要自行准备
4. 测试时可使用模拟数据
